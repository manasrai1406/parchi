What happens to a file

  1. 1
    Register
    The file is hashed, stored and given a reference number. An identical file is skipped as a duplicate.
  2. 2
    Extract with libraries
    pdfplumber, pandas or OCR read the vendor, date, items and totals.
  3. 3
    Validate
    Line items must add up. Receipt numbers and dates must be in sequence.
  4. 4
    AI only if you approve
    Files that fail checks wait in Needs review. Nothing is sent to Claude or OpenAI until you approve it.
